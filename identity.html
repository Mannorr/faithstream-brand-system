A centre-aligned vertical lockup — flame mark above a stacked wordmark — for formats where the horizontal lockup fights the canvas: posters, story covers, splash screens, square social tiles, event screens, merchandise. In wide horizontal spaces the horizontal lockup remains the default; the stacked version is never a substitute there.

One master file, many fills

Only one file exists: faithstream_stacked_white.png (white, transparent). Every colour version here is generated live by using that PNG as a CSS mask filled with a brand token — so the colour always comes from the palette, never from a re-export that could drift. Approved fills: #FFFFFF · #0A0A0F · #9B2F87 · #491440. Nothing else.

Minimum size rule

The full lockup must never appear narrower than 48px. Below that the wordmark stops being readable even at retina resolution. Always switch to faithstream_icon_purple.png at compact sizes, and to faithstream_favicon.png at 16px — never scale the full lockup down to it.

Co-brand lockup

1.5
Partner Logo
  1. Always use the wordmark-only file — not the full lockup with icon — in partner contexts.
  2. The separator height should match the cap-height of the taller of the two logos.
  3. On dark use wordmark_white; on light use wordmark_purple.
  4. FaithStream may sit on either side of the separator — left or right is equally valid.
  5. Never place partner branding above the FaithStream mark in a vertical stack.

Minimum clear space between the separator and each logo: 24px.

Asset inconsistency — flagged

icon_purple includes the full circular badge, but icon_white and icon_black are the bare flame mark with no circle — visible above, where they look smaller and float. This reads as an export inconsistency, not a design choice. Re-export white and black with the same badge treatment so all three are interchangeable.

Note on the wordmark typeface

The wordmark is set in a serif display face — "Miller Text" in House of Faith's original guide. The type rules below govern everything around the logo: UI, headlines, body copy. The logo is a fixed asset, not something redrawn in the type system, so changing the system typeface does not require a new logo file.

Where ember is allowed

Emphasis only — never chrome. Primary CTAs, the active nav state, a single highlighted figure in a data row, section markers, "new" badges. It must never become a background wash, a card fill, or a second brand colour competing with plum. Rule of thumb: if more than one ember element is visible in a viewport, one of them is wrong. Signal is rarer still — highlight and warning only.

Category colour — rebuilt

2.4 · fixes a functional failure
What was wrong

The five genre colours were #491440, #6C59A6, #702263, #9C8FC4 and #3D2870 — five purples. A system whose whole job is to make categories distinguishable at a glance could not do it. Below: five hues that can, anchored by brand magenta so the set still reads as FaithStream.

Usage rule

2.5 · revised in v2
The rule

Purple is the brand; everything structural is purple. Grounds, surfaces, nav, primary brand moments. Ember is permitted for emphasis under 2.3. The five category hues are permitted as identification under 2.4. Nothing else enters the palette without review.

Supersedes the v1 rule

v1 stated: "Purple carries every accent role in this system. No gold, no teal, no hue outside this family." That was recorded as a confirmed direction. v2 reverses it deliberately — the all-purple range was starving both emphasis and category identification. Flagging it plainly rather than quietly rewriting history: this needs a sign-off, not an assumption.

Functional colour

2.6 · resolved by 2.3

v1 left an open question: the live code uses #4ADE80 green for the "Match %" indicator — a Netflix convention that arrived without a brand decision. With a warm accent now in the system this resolves without a special case.

Section 03

Typography
System

One family, two cuts. Geist Sans carries everything from display to body; Geist Mono carries the annotation layer — labels, specs, tokens, filenames. The texture difference between them does the work two families used to.

Geist Sans

3.1 · four weights
Regular · 400 Aa
Medium · 500 Aa
Semibold · 600 Aa
Bold · 700 Aa

A neo-grotesque with a generous x-height and quietly geometric construction — the legibility of a UI face with enough character to carry a display line. Semibold is the display weight; 700 is reserved for the rare moment that needs to shout.

Set tight. Display sizes take -0.042em tracking, headings -0.028em, body 0. Tight tracking at large sizes is what separates a considered setting from a default one.

Geist Mono — the annotation layer

3.2

Every label, token name, hex value, filename and measurement on this site is set in Geist Mono at 11–13px with wide tracking. It reads as instrumentation rather than copy, which is exactly the distinction a brand system needs to make.

Migration note

The live product currently ships Syne for display and Inter for everything else, and one hero slide uses Cinzel. This page documents Geist as the system typeface going forward. That is a real change to a shipped brand decision, not just a change to this site — it needs a migration plan and a sign-off before the product follows. Cinzel should retire either way; it appears exactly once and nowhere in any rule.
